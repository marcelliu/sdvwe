# Креативы otkrovenno.online — UA · TikTok 9:16 + Instagram 3:4

5 разных роликов на украинском, каждый в двух форматах. Музыка и звуки синтезированы с нуля, без голоса.

| # | Название | Длина | Стиль / хук (первые 1–3 с) |
|---|---|---|---|
| 01 | «23:47» | 24,0 с | Ночной POV: телефон на столе вибрирует, уведомление «Ніка: Ти ще не спиш? 🙂» вылетает из экрана + «23:47. Вона написала першою.» |
| 02 | «3 кроки» | 22,0 с | Яркое UI-демо в цветах сайта: «Тут на «привіт» відповідають 😉» → 3 шага в телефоне |
| 03 | «Той самий вечір» | 24,0 с | Сплит-экран А/Б: холодный вечер против тёплого, на дропе музыки вариант Б забирает весь кадр |
| 04 | «Думав, що вже пізно» | 26,0 с | Кино-история в машине под дождём, пианино, спид-рамп на момент сообщения |
| 05 | «Що він хоче почути?» | 22,2 с | TikTok-квиз: 3 варианта сообщений, таймер 3-2-1, ✕/✓ и конфетти |

## Что в архиве

```
renders/9x16/   5 × MP4 для TikTok    1080×1920, H.264 High, 30 fps, AAC 256 кбит/с 48 кГц, ≈ −14 LUFS
renders/3x4/    5 × MP4 для Instagram 1080×1440, те же параметры
preview.html    открыть в браузере — все ролики на одной странице
source/
  backgrounds/  фоны без текста и интерфейса (тот же монтаж, MP4) — 9x16 и 3x4
  layers/       прозрачные слои текста/интерфейса (WebM VP9 с альфа-каналом), ложатся на фон 1:1
  layers_png/   прозрачные PNG ключевых моментов (текст, чат, эндкард) — для сборки в CapCut
  audio/        music/ (5 треков + стемы), sfx/ (библиотека звуков), mix/ (финальные миксы, −14 LUFS) — WAV 48 кГц 24 бит
  texts/        texts_ua.txt — все надписи с таймингами + альтернативные хуки для A/B
  in/           ваши исходные фото и видео
  project/      проект рендера (JavaScript/Node + ffmpeg): правишь текст → получаешь новые ролики
```

## Как перемонтировать в своём редакторе
1. На нижнюю дорожку — `source/backgrounds/<формат>/<ролик>_bg.mp4`.
2. Сверху — `source/layers/<формат>/<ролик>_overlay_alpha.webm` (с 0:00, масштаб 100 %).
   Прозрачность WebM читают Premiere Pro, DaVinci Resolve, Chrome. Если редактор (например, CapCut) альфу не видит —
   берите PNG из `layers_png/` или сгенерируйте ProRes 4444: `node src/render.mjs --creo c1 --prores`.
3. Звук — `source/audio/mix/<ролик>_mix.wav` (или музыка + отдельные SFX).

## Как поменять тексты / имя и перерендерить
Нужны Node.js 18+ и ffmpeg в PATH.
```
cd source/project
npm install
# положите исходные фото/видео в assets/in/ (копия лежит в source/in/)
npm run audio                                   # синтез музыки и SFX (≈1–3 мин)
node src/render.mjs --creo c1 --stills 1,10,20 # быстрый просмотр кадров в build/stills/
node src/render.mjs                             # все 5 роликов × 2 формата → build/renders/
```
- Все надписи — в `content/ua.json` (`[[слово]]` — выделение, `\n` — перенос). Имя «Ніка» / «Аліна» — `common.girl` / `common.girl2`.
- Сцены, тайминги, анимации — `src/creos/c1…c5_*.mjs`; дизайн-система (цвета бренда, пузыри чата, эндкард) — `src/engine/ui.mjs`.
- Первый запуск один раз строит кэш видео 60 fps (`assets/cache/`, несколько минут).

## Важно для модерации (позиционирование из вашего плана)
- На каждом эндкарде: «18+ · Розважальний чат · Персонажі вигадані, фото створені ШІ» (≥ 30 px, виден весь эндкард).
- Без обещаний встреч/свиданий, без сексуальных намёков, без утверждений о возрасте или семейном положении зрителя.
- Уведомление показано как часть сцены (на телефоне в кадре), а не как фейковое системное уведомление поверх экрана зрителя.
- `GIRL_1_1` (глубокий вырез) использована только плотным кадром лица/плеча — вырез в кадр не попадает.
- `GIRL_1_2` (блондинка с языком) — только как карточка «Аліна», которую свайпают в ролике 02 (~1 с). Если модерация придирается — замените фото.
- TikTok требует предварительного согласования рекламы dating/live-чатов и таргетинга 18+.

## Технические заметки
- Исходные видео были 720p/24 fps — подняты до 1080p с motion-интерполяцией до 60 fps (плавные замедления).
- Текст и кнопки держатся в безопасной зоне TikTok (сверху 150 px, справа 150 px, снизу 470 px).
- Шрифты: Onest (фирменный шрифт сайта), Literata, Noto Color Emoji — лицензия SIL OFL, в `project/assets/fonts/`.
