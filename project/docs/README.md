## Що в архіві

```
renders/9x16/   5 × MP4 для TikTok   1080×1920, H.264 High, 30 fps, AAC 256 кбіт/с 48 кГц, ≈ −14 LUFS
renders/3x4/    5 × MP4 для Instagram 1080×1440, ті самі параметри
preview.html    відкрити в браузері — усі ролики на одній сторінці
source/
  backgrounds/  фони без тексту та інтерфейсу (той самий монтаж, MP4) — 9x16 і 3x4
  layers/       прозорі шари тексту/інтерфейсу (WebM VP9 з альфа-каналом), лягають на фон 1:1
  layers_png/   прозорі PNG ключових моментів (текст, чат, ендкард) — для збірки в CapCut
  audio/        music/ (5 треків + стеми), sfx/ (бібліотека звуків), mix/ (фінальні мікси, −14 LUFS) — WAV 48 кГц 24 біт
  texts/        texts_ua.txt — усі написи з таймінгами + альтернативні хуки для A/B
  in/           ваші вихідні фото та відео
  project/      проєкт рендера (JavaScript/Node + ffmpeg): правиш текст → отримуєш нові ролики
```

## Як перемонтувати у своєму редакторі
1. Покладіть `source/backgrounds/<формат>/<ролик>_bg.mp4` на нижню доріжку.
2. Зверху — `source/layers/<формат>/<ролик>_overlay_alpha.webm` (позиція 0:00, масштаб 100 %).
   Прозорість у WebM читають Premiere Pro, DaVinci Resolve, Chrome; якщо ваш редактор (наприклад, CapCut) не бачить альфу —
   беріть PNG із `layers_png/` або згенеруйте ProRes 4444: `node src/render.mjs --creo c1 --prores`.
3. Звук — `source/audio/mix/<ролик>_mix.wav` (або музика + окремі SFX).

## Як змінити тексти / ім'я і перерендерити
Потрібні Node.js 18+ і ffmpeg у PATH.
```
cd source/project
npm install
# покладіть вихідні фото/відео в assets/in/ (копія є в source/in/)
npm run audio                                   # синтез музики й SFX (≈1–3 хв)
node src/render.mjs --creo c1 --stills 1,10,20 # швидкий перегляд кадрів у build/stills/
node src/render.mjs                             # усі 5 роликів × 2 формати → build/renders/
```
- Усі написи — у `content/ua.json` (`[[слово]]` — виділення, `\n` — перенос). Ім'я «Ніка» / «Аліна» — `common.girl` / `common.girl2`.
- Сцени, таймінги, анімації — `src/creos/c1…c5_*.mjs`; дизайн-система (кольори бренду, бульбашки чату, ендкард) — `src/engine/ui.mjs`.
- Перший запуск один раз створює кеш відео 60 fps (`assets/cache/`, кілька хвилин).

## Важливо для модерації (позиціонування з вашого плану)
- На кожному ендкарді: «18+ · Розважальний чат · Персонажі вигадані, фото створені ШІ» (≥ 30 px, видно весь ендкард).
- Без обіцянок зустрічей/побачень, без сексуальних натяків, без тверджень про вік чи сімейний стан глядача.
- Сповіщення показане як частина сцени (на телефоні в кадрі), а не як фальшиве системне сповіщення поверх екрана глядача.
- `GIRL_1_1` (глибокий виріз) використано лише щільним кадром обличчя/плеча — виріз у кадр не потрапляє.
- `GIRL_1_2` (блондинка, язик) — лише як картка «Аліна», яку свайпають у ролику 02 (~1 с). Якщо модерація прискіпується — замініть фото.
- TikTok вимагає попереднього погодження реклами dating/live-чатів і таргетингу 18+.

## Технічні нотатки
- Вихідні відео були 720p/24 fps — підняті до 1080p з motion-інтерполяцією до 60 fps (плавні сповільнення).
- Текст і кнопки тримаються в безпечній зоні TikTok (верх 150 px, праворуч 150 px, низ 470 px).
- Шрифти: Onest (фірмовий шрифт сайту), Literata, Noto Color Emoji — ліцензія SIL OFL, у `project/assets/fonts/`.
